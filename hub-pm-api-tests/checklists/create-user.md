# Чек-лист: создание пользователя

Всего проверок: 110

Подход: валидный тест - все поля заполнены корректными данными. Дальше каждое поле меняется по одному, остальные остаются валидными. Каждая проверка - отдельный автотест в конструкторе.

## Данные пользователя

| Поле | Позитивные проверки | Негативные и граничные проверки |
|---|---|---|
| Все поля | валидные данные | - |
| Имя | латиница, один символ, длинная строка | спецсимволы, цифры, эмодзи, только пробелы, пробелы по краям, пустое значение, null |
| Фамилия | латиница, один символ, длинная строка | спецсимволы, цифры, эмодзи, только пробелы, пробелы по краям, пустое значение, null |
| Отчество | латиница, один символ, длинная строка | спецсимволы, цифры, эмодзи, только пробелы, пробелы по краям, пустое значение, null |
| Email | в верхнем регистре | уже существующего пользователя, без @, без имени, без домена, кириллицей, со спецсимволами, с пробелами по краям, очень длинный, пустое значение, null |
| Дата рождения | - | будущая дата, возраст меньше 18 лет, очень старая дата, несуществующая дата, неверный формат, пустое значение, null |
| Цвет аватара | существующий цвет | несуществующее название, спецсимволы, эмодзи, очень длинная строка, пустое значение, null |
