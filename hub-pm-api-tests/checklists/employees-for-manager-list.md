# Чек-лист: получение списка сотрудников руководителя

Всего проверок: 47

Подход: валидный тест - все поля заполнены корректными данными. Дальше каждое поле меняется по одному, остальные остаются валидными. Каждая проверка - отдельный автотест в конструкторе.

| Поле | Позитивные проверки | Негативные и граничные проверки |
|---|---|---|
| Все поля | валидные данные | - |
| Поиск | часть фамилии, существующая фамилия, имя, email, другой регистр | 300 символов, спецсимволы, эмодзи, только пробелы, несуществующее значение, пустое значение, null |
| Фильтр по статусам | активные, ожидает активации, уволенные, несколько статусов | значение вне перечисления, отрицательное значение, дробное значение, дубли значений, пустой массив, null |
| Признак "включить текущего пользователя" | включен, выключен | null |
| Признак "исключить администраторов проекта и владельца" | включен + существующий проект, выключен | включен + проект не передан, null |
| Id пользователя | сотрудник без подчиненных | несуществующее значение, 0, отрицательное значение, дробное значение, максимальное число, минимальное число, пустое значение, null |
| Id проекта | - | несуществующий проект, 0, отрицательное значение, дробное значение, максимальное число, минимальное число, пустое значение, null |
