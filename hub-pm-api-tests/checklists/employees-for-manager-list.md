# Чек-лист: получение списка сотрудников руководителя

Всего проверок: 47


Подход: валидный тест - все поля заполнены корректными данными. Дальше каждое поле меняется по одному, остальные остаются валидными. Каждая проверка - отдельный автотест в конструкторе.

| Поле | Позитивные проверки | Негативные и граничные проверки |
|---|---|---|
| Все поля | валидные данные | - |
| Search | часть фамилии, существующая фамилия, имя, email, другой регистр | 300 символов, спецсимволы, эмодзи, только пробелы, несуществующее значение, пустое значение, null |
| Statuses | активные, ожидает активации, уволенные, несколько статусов | значение вне перечисления, отрицательное значение, дробное значение, дубли значений, пустой массив, null |
| IncludeCurrentUser | true, false | null |
| IgnoreProjectAdminsAndOwner | true + существующий проект, false | true + ProjectId=null, null |
| UserId | сотрудник без подчиненных | несуществующее значение, 0, отрицательное значение, дробное значение, максимум Int64, минимум Int64, пустое значение, null |
| ProjectId | - | несуществующий проект, 0, отрицательное значение, дробное значение, максимум Int64, минимум Int64, пустое значение, null |
