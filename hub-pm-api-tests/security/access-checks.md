# Проверки прав доступа

Каждый тест запускается на дашборде под токенами разных пользователей - 12 аккаунтов с разными ролями и доступами в рабочей области. Результат каждого запуска сверяется с ожидаемым: пользователь с доступом получает данные, пользователь без доступа получает ошибку доступа.

Проверки прав доступа выполняются в самом конце, после функциональных проверок метода.

## Роли пользователей

1. Владелец
2. Администраторы проекта
3. Администраторы рабочей области
4. Глава команды
5. Обычные сотрудники
6. Неавторизованный пользователь

## Проверка 1. Получение вечерней сводки по существующему пользователю

- Запросов: 12, под токенами пользователей всех ролей

## Проверка 2. Добавление тега в проект

- Запросов: 12, под токенами пользователей всех ролей

## Проверка 3. Назначение задачи в очередность сотруднику

- Запросов: 11, под токенами пользователей всех ролей
