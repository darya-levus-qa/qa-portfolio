# Hub-PM - API-тесты (WebSocket)
Hub-PM - система управления проектами. Тестировала WebSocket API: проверки по полям, сценарии из юнитов, проверки прав доступа.

## Содержимое
- `scenarios/` - сценарии из юнитов
- `security/` - проверки прав доступа
- `screenshots/` - как тесты выглядят в конструкторе и Postman
