# UI-автотесты

Автотесты интерфейса системы управления проектами. Тесты собраны в конструкторе компании без написания кода и запускаются в эмуляторе браузера Chromium.

## Как устроены тесты

- **Кроссбраузерность.** Каждый тест поддерживает запуск в Chrome, Firefox и Safari.
- **Переменные.** Логин и пароль не вписаны в тест, а подставляются из переменных. Если данные аккаунта меняются, правится одна переменная, а не каждый тест.
- **Локаторы.** Элементы на странице находятся по XPath-локаторам.
- **Типы шагов:** открытие страницы по адресу, ввод текста в поле, клик левой кнопкой мыши, клик правой кнопкой мыши (контекстное меню).
- **Приоритеты.** У каждого теста задан приоритет: критичный или высокий. По приоритету определяется, какие тесты запускать в первую очередь при регрессе.
- **Общий блок авторизации.** Первые шаги одинаковы во всех тестах, поэтому каждый тест можно запустить отдельно, с чистого состояния.

## Покрытие

| Тест | Раздел | Действие | Приоритет |
|---|---|---|---|
| Создание дашборда | Дашборды | создание + отображение в списке | критичный |
| Создание папки с переменными | Источники данных | создание | высокий |
| Создание подпапки внутри папки | Автотесты | создание через контекстное меню | высокий |

## Общие шаги: авторизация и переход в проект

| Шаг | Действие | Данные |
|---|---|---|
| 1 | Открыть страницу входа | адрес тестового стенда |
| 2 | Ввести логин | из переменной |
| 3 | Ввести пароль | из переменной |
| 4 | Нажать "Войти" | - |
| 5 | Выбрать тестовый проект | тестовый проект для регресса |
| 6 | Перейти в раздел автотестов проекта | - |

## Тест 1. Создание дашборда и появление его в списке как вкладки браузера

**Приоритет:** критичный

**Цель:** проверить, что новый дашборд создается через кнопку "+" и сразу появляется в списке дашбордов.

**Предусловия**

1. Есть тестовый пользователь с доступом к проекту
2. Логин и пароль пользователя заданы в переменных

**Тестовые данные:** название дашборда "Тестовый дашборд - 1"

| Шаг | Действие |
|---|---|
| 1-6 | Общие шаги |
| 7 | Открыть раздел "Дашборды" |
| 8 | Нажать "+" |
| 9 | Ввести название дашборда |
| 10 | Подтвердить создание |

**Ожидаемый результат:** дашборд создан и отображается в списке как вкладка браузера

## Тест 2. Создание папки с переменными

**Приоритет:** высокий

**Цель:** проверить создание папки в разделе "Источники данных", где хранятся переменные для тестов.

**Предусловия**

1. Есть тестовый пользователь с доступом к проекту
2. Логин и пароль пользователя заданы в переменных

**Тестовые данные:** название папки "Папка для источников данных"

| Шаг | Действие |
|---|---|
| 1-6 | Общие шаги |
| 7 | Открыть раздел "Источники данных" |
| 8 | Нажать "+" |
| 9 | Выбрать "Создать папку" |
| 10 | Ввести название папки |

**Ожидаемый результат:** папка создана и отображается в разделе "Источники данных"

## Тест 3. Создание подпапки внутри папки

**Приоритет:** высокий

**Цель:** проверить создание вложенной папки через контекстное меню (правая кнопка мыши).

**Предусловия**

1. Есть тестовый пользователь с доступом к проекту
2. Логин и пароль пользователя заданы в переменных
3. В разделе автотестов есть папка автотестов

**Тестовые данные:** название подпапки "Тестовая папка автотестов"

| Шаг | Действие |
|---|---|
| 1-6 | Общие шаги |
| 7 | Раскрыть раздел автотестов |
| 8 | Нажать правой кнопкой мыши на папку автотестов |
| 9 | Выбрать в контекстном меню пункт создания подпапки |
| 10 | Ввести название подпапки |

**Ожидаемый результат:** подпапка создана и отображается внутри папки автотестов
